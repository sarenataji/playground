# The Playground of Sarena

A new studio site. Not a case-study grid — a room you enter.

The first function is the material: **ink**. You draw a circle to melt the frost (Zero), the hero crops through living blobs and a pointer-tracked 3D stamp (Lando Norris), and a GPU fluid is both the cursor and a table you can paint on (Slosh).

Visual identity follows the editorial frame: cream paper, Didone type, circular studio stamp, hand-drawn arrow. The three reference sites donate motion, not branding.

## Run

```sh
pnpm install
pnpm dev
```

Opens at `http://127.0.0.1:5177`.

## Stack

Vite, React 19, TypeScript, Three.js / R3F, GSAP, Lenis, custom WebGL2 fluid, custom metaball field.

Research and the build roadmap live in `docs/`.
